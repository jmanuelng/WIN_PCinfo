# Security

Report vulnerabilities privately. Do not open a public issue, discussion, or pull request that describes an exploitable defect or includes Restricted Diagnostic Evidence.

Use GitHub private vulnerability reporting:

https://github.com/jmanuelng/WIN_PCinfo/security/advisories/new

Include only what a maintainer needs to reproduce the issue. Never attach a Protected Evidence Package, Assessment Record, exported HTML report, Recipient Profile, fingerprint, credential, token, recovery material, or real tenant, device, or host identifier.

This project has no SLA. Acknowledgement and repair happen on a best-effort basis.
