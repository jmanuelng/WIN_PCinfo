# Issue 56 validation projection

This public projection contains release-owned contracts and identifier-free synthetic validation outcomes only. It contains no recovery material, protector identifier, AppLocker or WDAC policy body, GPO identity, link identity, setting identity, policy value, principal SID, package path, or private Assessment Record value.

## Observable evidence

| Gate | Public-safe result |
| --- | --- |
| Frozen authority | One offline Administrator operation freezes fifteen structured sources, thirty-five Evidence Scopes, finite catalogs, exact bounds, no installation, no refresh, and no write authority in the immutable Preparation Plan. |
| Three layers | Applied Policy Evidence, Configured Policy Signals, and Current Control State remain distinct, and BitLocker, VBS, WDAC, and AppLocker do not collapse those layers. |
| BitLocker privacy | Only bounded operating-system-volume conversion, protection, encryption-method, lock, and protector type/count facts are admitted. Recovery secrets, PINs, keys, PFX data, and unnecessary protector identifiers are rejected at the collector boundary. |
| Device-reported VBS | VBS, Credential Guard, memory integrity, and user-mode code integrity use device-reported structured values only and never claim policy provenance. |
| WDAC honesty | Structured `CiTool -lp -json` inventory is used on supported builds only. Unsupported Windows 10 inventory remains explicit incomplete coverage instead of parsed text. |
| AppLocker channel separation | Group Policy and CSP channels remain separate. A concrete disagreement becomes `NeedsAttention`; incomplete channel evidence becomes `Indeterminate`. |
| Constraint boundaries | Local BitLocker protection, passive Defender mode, tamper protection, and virtualized VBS are surfaced as explicit constraints. Local BitLocker state never becomes a recovery-escrow claim, and virtual evidence never becomes physical TPM attestation. |
| Generated application | Forty closed cases exercise Preparation, the bounded Administrator worker, SYSTEM-denial context, canonical record, beginner report, protected package reopen, one terminal outcome, and verified cleanup. Public validation output contains only states, findings, counts, and safety assertions. |

The fixture seam cannot supply recovery material, protector identifiers, AppLocker or WDAC policy XML, a command, a script path, a network permission, or a mutation.
