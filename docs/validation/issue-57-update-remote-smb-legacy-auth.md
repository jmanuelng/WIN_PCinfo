# Issue 57 validation projection

This public projection contains release-owned contracts, identifier-free synthetic outcomes, and public-safe assertions only. It contains no update-policy values, remote-management listener details, SMB posture values, legacy-authentication masks, package path, or private Assessment Record value.

## Observable evidence

| Gate | Public-safe result |
| --- | --- |
| Frozen operations | One offline Administrator operation and one predefined offline SYSTEM sub-plan freeze exact Windows-native sources, execution context, field catalogs, dependencies, attempt/deadline/output bounds, cleanup proof, and the no-install/no-download/no-write contract in the immutable Preparation Plan. |
| Windows Update and WUfB | The slice reads only documented local Policy Result fields and documented registry mappings for feature-update deferral, quality-update deferral, and `DisableDualScan`. It does not trigger Windows Update, start a scan, infer tenant intent, or guess that one source wins globally. |
| Remote management | RDP and WinRM remain local configuration evidence only. Service mode/state, authentication settings, and listener state are kept separate from remote reachability, successful logon, firewall traversal, or organization-wide exposure claims. |
| SMB posture | SMB client posture, SMB server posture, and SMB1 optional-feature state are collected from structured objects only. The slice does not enumerate shares or sessions and does not infer active SMB1 traffic from feature state alone. |
| Legacy authentication | LAN Manager compatibility and NTLM minimum-session-security evidence use finite documented registry names and masks only. Missing, malformed, or denied values remain explicit gaps and never become a claim that a legacy protocol was not used. |
| Evidence honesty | Unsupported build, missing class or property, absent listener, denied source, malformed value, stale upstream registry signal, incomplete catalog, and partial coverage remain explicit bounded gaps. None of those conditions becomes a false `Disabled`, `NotConfigured`, `NotReachable`, or `NotUsed` conclusion. |
| Privacy | Generated public output is checked to keep update-policy values, remote-management details, SMB values, and legacy-authentication masks out of the public projection. Only coverage states, findings, counts, and fixed safety assertions leave the protected package. |
| Generated application | Closed synthetic fixtures exercise configured, unconfigured, unsupported, denied, listener-combination, SMB1-feature, signing/encryption/guest, stale-value, malformed-mask, and localized-output paths through the generated Effective Policy application. |

The synthetic seam does not run Windows Update, open an RDP or WinRM session, probe a remote endpoint, enumerate SMB shares or sessions, change a feature, alter a service, or install a tool.
